# 區域網路裝置掃描器

## 功能

- 自動列出電腦目前可用的私人 IPv4 位址。
- 有多個 IP 時，必須先指定要搜尋的網路介面。
- 搜尋所選 IP 所在的 `/24`（C Class）網段，共 `.1` 到 `.254`。
- 顯示被占用的 IP、可取得的裝置名稱、推測裝置類型、MAC 位址與回應時間。
- 支援中途停止搜尋。

## 使用方式

1. 執行 `LanDeviceScanner.exe`。
2. 若畫面列出多個本機 IPv4，選擇連到目標家用網路的那一個。
3. 按「開始搜尋」，等待清單完成。

搜尋完成時，程式會掃描完整的 `.1` 到 `.254`，但清單只顯示有回應或可由 ARP 發現的 IP。例如清單最後一筆是 `.27`，代表 `.28` 到 `.254` 沒有發現裝置，並不是掃描停在 `.27`。

裝置名稱取自區域網路的反向 DNS；類型是依名稱與常見服務推測，並不保證準確。某些裝置會封鎖 Ping、隱藏名稱或因 AP 隔離而無法被發現。MAC 位址通常只能取得同一個廣播網段內的裝置。

請只掃描自己擁有或獲准管理的網路。

## 系統需求

- Windows 10 或 Windows 11
- Windows 內建 .NET Framework 4.x
- 不需安裝，不需網際網路

## 重新建置

在 PowerShell 執行：

```powershell
.\build-lan-device-scanner.ps1
```

完成後執行檔位於 `release\LanDeviceScanner.exe`。
